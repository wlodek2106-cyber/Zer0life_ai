Frequently asked questions

What is Zer0Life Run?

Zer0Life Run is a Telegram Mini App that combines running and daily activity with Web3 game features and in-game ZRL rewards.

Do I need an invite code to register?

No. You can choose to register without a referral. The one-time registration bonus is the same either way.

Are ZRL rewards or earnings guaranteed?

No. Reward eligibility depends on the current game rules and activity verification. Token values and withdrawal availability can change; no financial return is guaranteed.
